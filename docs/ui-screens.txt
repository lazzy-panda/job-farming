JOB FARM — КАРТА UI: ЭКРАНЫ, ЭЛЕМЕНТЫ, МОДАЛКИ
================================================
Стек: Angular 21 (standalone) + Angular Material. Актуально на 26.08.2026.
Формат: экран → секции → элементы. В [скобках] — имя компонента.

──────────────────────────────────────────────
0. ОБЩИЙ КАРКАС (присутствует на каждом экране)
──────────────────────────────────────────────
ШАПКА [dashboard-header]
├─ Логотип «Job Farm» (ссылка на /)
├─ Навигация
│  ├─ «Добавить источник» → /sources/new
│  ├─ «Шаблоны»           → /templates
│  └─ «Настройки»         → /settings
└─ Действия (справа)
   ├─ Кнопка «Сортировка» [sort-menu] — только на дашборде (showSort)
   └─ Кнопка «Обновить» (иконка refresh) — перезагрузка данных / запуск скрейпа

СИСТЕМНЫЕ УВЕДОМЛЕНИЯ
└─ Snackbar (Material) — тосты: «Сбор вакансий запущен», «Вакансия удалена»,
   «Текст скопирован», ошибки загрузки/сохранения

──────────────────────────────────────────────
1. ЭКРАН «ДАШБОРД» — маршрут /  [dashboard-page]
──────────────────────────────────────────────
├─ Шапка (см. п.0, с кнопкой «Сортировка»)
│
├─ ПАНЕЛЬ ПЛАНА [plan-panel]
│  ├─ Блок очков
│  │  ├─ «Очки сегодня» N/порог (6 будни, 10 сб, 0 вс; зелёная рамка при выполнении)
│  │  ├─ «Очки недели» N/минимум (35 неделя 1, дальше 45)
│  │  └─ Красный флаг «2 дня по нулям» (warning-иконка + тултип)
│  ├─ Кнопки ручных очков (4 шт.)
│  │  ├─ «Касание +3» · «Созвон +8» · «Пост +5» · «Артефакт +4»
│  ├─ Строка чекпоинта (ближайший из трёх: 26.09 / 24.10 / 21.11)
│  │  ├─ чип «отклики N/норма» (+ разбивка адаптированные/шаблонные)
│  │  ├─ чип «ответы N/норма» · чип «собесы N/норма»
│  │  └─ чипы-счётчики: офферы, касания, созвоны, посты, артефакты
│  └─ Блок фоллоу-апов (если есть отклики без ответа > 3 дней)
│     ├─ Кнопка-тогл «Фоллоу-апы: N без ответа > 3 дней» (раскрывает список)
│     └─ Строка фоллоу-апа (по одной на отклик)
│        ├─ «N дн.» (сколько ждём) · название вакансии (ссылка)
│        └─ Кнопки «Ответили» (→ replied) · «Собес» (→ interview, +8 очков)
│
├─ ПОИСК [job-search]
│  ├─ Поле поиска (иконка search, плейсхолдер, кнопка очистки ×)
│  │  └─ синтаксис: пробел = И, «|» = ИЛИ
│  ├─ Счётчик «Найдено: X / Y»
│  ├─ Чипы-пресеты: «DM/РП (план)» · «Удалёнка» · «Angular (запас)»
│  └─ Чипы-источники (иконки): Telegram · RSS · API (фильтр по типу источника)
│
├─ Прогресс-бар загрузки (indeterminate, при loading)
│
├─ СПИСОК КАРТОЧЕК ВАКАНСИЙ [job-cards] (грид)
│  └─ КАРТОЧКА ВАКАНСИИ (по одной на вакансию)
│     ├─ Шапка: аватар канала (или инициал) · заголовок (из парсера) · формат работы
│     ├─ Инфо-строка: дата публикации · ссылка на источник (хост, напр. hh.ru)
│     │  · зарплата (из парсера) · название канала/источника
│     ├─ Строка «Опыт:»
│     ├─ Описание
│     │  ├─ Текст (свёрнут/развёрнут, кнопка «Развернуть/Свернуть»)
│     │  ├─ Кнопка <code> — оверлей «Parser JSON» (см. МОДАЛКИ)
│     │  ├─ Кнопка «Перевести» (translate) → блок «Перевод (RU)»
│     │  └─ Статусы перевода: «Переводим текст…» / ошибка
│     ├─ «Компания: …» · «Контакт: ссылка» (если распарсен)
│     └─ ПАНЕЛЬ ДЕЙСТВИЙ (низ карточки)
│        ├─ Чип статуса: «Отклик отправлен» (зелёный) / «Отложено» (оранжевый)
│        ├─ ⭐ Отложить/убрать из шортлиста (статус shortlisted)
│        ├─ ✎ Адаптированный отклик (+2 очка; статус → applied)
│        ├─ ⚡ Быстрый отклик по шаблону (+1 очко; статус → applied)
│        └─ 🗑 Удалить (native confirm «Удалить вакансию …?»)
│  └─ Пустое состояние: «Нет вакансий. Добавьте или измените фильтры.»
│
└─ ПАГИНАЦИЯ [pagination]
   ├─ «Показано X–Y из Z» / «Нет данных»
   ├─ Кнопки « ‹ [страницы с …] › »
   └─ Селект размера страницы (20/50/100)

──────────────────────────────────────────────
2. ЭКРАН «ИСТОЧНИКИ» — маршрут /sources/new  [source-page]
──────────────────────────────────────────────
├─ Шапка (подзаголовок «Вакансии собираются автоматически…»)
├─ ФОРМА ДОБАВЛЕНИЯ [source-create]
│  ├─ Поле «Адрес» (t.me/… или RSS-URL; иконка telegram при t.me)
│  ├─ Автоопределение типа: подпись «Telegram канал» / «RSS лента»
│  ├─ Сообщение об ошибке валидации URL
│  └─ Кнопка «Добавить» (disabled при пустом/невалидном URL)
├─ СПИСОК «Добавленные источники»
│  └─ Строка источника: № · иконка типа · название · URL
│     · счётчик подписчиков (для TG) · 🗑 удалить
│  └─ Пустое состояние: «Источники пока не добавлены»
└─ Пагинация [pagination]

──────────────────────────────────────────────
3. ЭКРАН «РЕЗЮМЕ И ШАБЛОНЫ» — маршрут /templates  [templates-page]
──────────────────────────────────────────────
├─ Шапка (подзаголовок про версии резюме и автопометку откликов)
├─ КОЛОНКА «РЕЗЮМЕ — ВЕРСИИ ДЛЯ РАССЫЛКИ»
│  ├─ Список версий резюме
│  │  └─ Строка резюме:
│  │     ├─ ⭐ «по умолчанию» (жёлтая = активная; клик переключает дефолт,
│  │     │   дефолтная версия штампуется в каждый отклик)
│  │     ├─ Имя версии («DM v1») · заголовок (роль в шапке)
│  │     ├─ A/B-статистика: «отклики N · ответы N · собесы N»
│  │     └─ Действия: копировать текст · редактировать · удалить (confirm)
│  ├─ Пустое состояние (подсказка про A/B)
│  └─ ФОРМА «Новая версия резюме / Редактирование»
│     ├─ «Имя версии» · «Заголовок резюме» · «Текст резюме» (textarea)
│     ├─ «Заметки (под какие вакансии)»
│     └─ Кнопки «Добавить/Сохранить» · «Отмена» (в режиме правки)
└─ КОЛОНКА «ШАБЛОНЫ ПИСЕМ И ОТКЛИКОВ»
   ├─ Список шаблонов
   │  └─ Строка шаблона: название · канал (telegram/email/hh/habr)
   │     · копировать · редактировать · удалить (confirm)
   ├─ Пустое состояние
   └─ ФОРМА «Новый шаблон письма / Редактирование»
      ├─ «Название» · селект «Канал» · «Текст» (textarea)
      └─ Кнопки «Добавить/Сохранить» · «Отмена»

──────────────────────────────────────────────
4. ЭКРАН «НАСТРОЙКИ» — маршрут /settings  [settings-page]
──────────────────────────────────────────────
├─ Шапка (подзаголовок «SMTP/порты…»)
└─ ФОРМА НАСТРОЕК [settings-form] (одна карточка)
   ├─ Секция SMTP: host · port · user · pass · from · «Порт API»
   ├─ Секция «Telegram HTTP»:
   │  ├─ Задержка (мс) · Джиттер (мс) · Макс страниц
   │  ├─ User-Agent · Keyword filters (через запятую)
   │  ├─ Тогл «Прокси»
   │  └─ Proxy host · port · user · pass
   └─ Кнопка «Сохранить настройки»

──────────────────────────────────────────────
5. МОДАЛКИ И ОВЕРЛЕИ
──────────────────────────────────────────────
├─ «СОРТИРОВКА» [sort-menu] — cdk-оверлей из шапки дашборда
│  ├─ Заголовок «Сортировка»
│  ├─ Опции (label + подпись): по дате ↓ / по дате ↑ / по компании
│  └─ Галочка у активной; закрытие по клику на фон
│
├─ «PARSER JSON» [vacancy-parse-json] — cdk-оверлей с карточки вакансии (кнопка <code>)
│  ├─ Заголовок «Parser JSON» + кнопки: копировать · перепарсить · закрыть
│  └─ Тело: JSON результата парсера / «Парсинг…» / «Ошибка парсинга» /
│     «Парсер выключен на API (VACANCY_PARSER_ENABLED=1)» / «Нет данных»
│
├─ NATIVE CONFIRM (браузерные диалоги подтверждения)
│  ├─ Удаление вакансии («Удалить вакансию …?»)
│  ├─ Удаление резюме («Удалить резюме …?»)
│  └─ Удаление шаблона письма
│
└─ SNACKBAR-ТОСТЫ (Material, внизу) — статусы операций на всех экранах

──────────────────────────────────────────────
6. КОМПОНЕНТЫ БЕЗ МАРШРУТА / НЕ ПОДКЛЮЧЕНЫ (legacy)
──────────────────────────────────────────────
├─ [proxy-page] + [proxy-create] — экран управления прокси (форма ~118 строк:
│  host/port/protocol/логин/UA/cookie; список с чипами Активен/Неактивен,
│  тогл/редактировать/удалить). МАРШРУТА НЕТ — на экран не попасть из UI.
│  Прокси сейчас управляются скриптами (npm run proxies:refresh).
├─ [job-table] — табличный вид вакансий (колонки: заголовок/компания/статус/
│  источник/ссылка/действия «Copy Reply») — нигде не используется,
│  дашборд показывает только карточки.
├─ [job-create] — форма ручного добавления вакансии — не используется.
├─ [job-filters] — фильтры статус/источник через mat-menu — не используется.
├─ [filters-menu] — те же фильтры через cdk-оверлей (дубль job-filters) — не используется.
└─ [status-card] — карточка статуса скрейпа (последний опрос, пустые прогоны,
   пауза, ошибка) — не используется.

Примечание: в [dashboard-page] есть локальные фильтры status/sourceId (filters:
{status, sourceId}) — но UI-элемент для них не подключён (см. п.6), фактический
фильтр по источникам — чипы в [job-search].
